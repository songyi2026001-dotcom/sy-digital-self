# S.Y / Digital Self

A personal digital space for works, notes, fragments, collections, now, and archive.

## Start

```bash
npm install
npm run dev
```

Then open the local URL Astro prints in the terminal.

## Structure

- `/` — Home
- `/works` — finished works and projects
- `/notes` — longer thoughts
- `/fragments` — short observations and unfinished ideas
- `/collections` — things collected: music, books, images, places...
- `/now` — what is happening now
- `/archive` — chronological archive

Content is intentionally placeholder-first. Replace it gradually with your own material.
